## Usage

Provide `size` for a square, or both `width` and `height` for custom dimensions. Components use those logical dimensions for the source and native display size; CSS can override the display. Use `#rrggbbaa` colors when you need transparency; SVG, PNG, and WebP preserve alpha, while JPEG composites transparent colors over white.

<View title="React" icon="https://pictum.dev/v1/icons/devicon:react.svg">
  <CodeGroup>
    ```tsx Component
    import { Placeholder } from "@pictum/react";

    export function Example() {
      return (
        <Placeholder
          width={640}
          height={360}
          background="#ede9fe"
          color="#4c1d95"
          text="Product preview"
          alt="Product preview placeholder"
        />
      );
    }
    ```

    ```tsx Hook
    import { usePlaceholder } from "@pictum/react";

    export function Example() {
      const asset = usePlaceholder({
        size: 320,
        format: "webp",
        density: 2,
        text: "Coming soon",
      });

      return (
        <img
          src={asset.url}
          alt="Coming soon placeholder"
          width={320}
          height={320}
        />
      );
    }
    ```
  </CodeGroup>

  #### Props

  <ResponseField name="size" type="integer">
    The `size` prop or hook option selects the square dimension form. Use it alone, never with `width` or `height`. Accepted range: `16`-`2048`; logical area cannot exceed `4,194,304` pixels.
  </ResponseField>

  <ResponseField name="width" type="integer">
    The `width` prop or hook option selects the custom dimension form. Provide it with `height`, never with `size`. Accepted range: `16`-`4096`; logical width multiplied by height cannot exceed `4,194,304` pixels.
  </ResponseField>

  <ResponseField name="height" type="integer">
    The `height` prop or hook option selects the custom dimension form. Provide it with `width`, never with `size`. Accepted range: `16`-`4096`; logical width multiplied by height cannot exceed `4,194,304` pixels.
  </ResponseField>

  <ResponseField name="format" type='"svg" | "jpg" | "png" | "webp"' default="svg">
    The `format` prop or hook option selects the source encoding. Components and hooks default to SVG.
  </ResponseField>

  <ResponseField name="density" type="2 | 3" default="standard density">
    The `density` prop or hook option is only valid for JPG, PNG, and WebP. Omit it for standard density. After applying density, each source axis cannot exceed `4096` pixels and source area cannot exceed `4,194,304` pixels; logical display dimensions do not change.
  </ResponseField>

  <ResponseField name="background" type="string" default="#f1eef8">
    The `background` prop or hook option sets the fill color and must use `#rrggbb` or `#rrggbbaa` syntax.
  </ResponseField>

  <ResponseField name="color" type="string" default="#6d28d9">
    The `color` prop or hook option sets the label color and must use `#rrggbb` or `#rrggbbaa` syntax.
  </ResponseField>

  <ResponseField name="text" type="string" default="width x height">
    The `text` prop or hook option accepts up to `64` Unicode characters. Pass an empty string to suppress the label. The label is omitted when logical width is below `96` or logical height is below `64`.

  #### Usage

  ```html
  <img
    src="https://pictum.dev/v1/placeholder.svg?width=640&height=360&background=%23ede9fe&color=%234c1d95&text=Product+preview"
    alt="Product preview placeholder"
    width="640"
    height="360"
  />
  ```

  #### Parameters

  <ResponseField name="size" type="integer">
    The `size` query parameter creates a square from `16` to `2048` pixels. Provide exactly `size`, or both `width` and `height`, never both forms.
  </ResponseField>

  <ResponseField name="width" type="integer">
    The `width` query parameter creates a custom-dimension placeholder. Provide it with `height`, never with `size`. Accepted range: `16`-`4096`.
  </ResponseField>

  <ResponseField name="height" type="integer">
    The `height` query parameter creates a custom-dimension placeholder. Provide it with `width`, never with `size`. Accepted range: `16`-`4096`; logical width multiplied by height cannot exceed `4,194,304` pixels.
  </ResponseField>

  <ResponseField name="format" type='"svg" | "jpg" | "png" | "webp"' required>
    The path extension selects the response encoding.
  </ResponseField>

  <ResponseField name="density" type="2 | 3" default="standard density">
    The optional `density` query parameter is only valid for JPG, PNG, and WebP. Omit it for standard density. After applying density, each source axis cannot exceed `4096` pixels and source area cannot exceed `4,194,304` pixels. Set explicit logical `width` and `height` attributes when rendering the URL.
  </ResponseField>

  <ResponseField name="background" type="string" default="#f1eef8">
    The `background` query parameter sets the fill color. Use a six- or eight-digit hex color with or without `#`; encode `#` as `%23` in a URL.
  </ResponseField>

  <ResponseField name="color" type="string" default="#6d28d9">
    The `color` query parameter sets the label color. Use a six- or eight-digit hex color with or without `#`; encode `#` as `%23` in a URL.
  </ResponseField>

  <ResponseField name="text" type="string" default="width x height">
    The `text` query parameter accepts up to `64` Unicode characters and must be URL-encoded. Use an empty value to suppress the label. The label is omitted when logical width is below `96` or logical height is below `64`.

    <Warning>
      Text may appear in logs and public, cacheable URLs. Do not use sensitive information.
    </Warning>
  </ResponseField>
</View>
