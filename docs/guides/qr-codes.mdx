## Usage

Integration components and helpers encode values for you. They do not expose raster source size; use `width`, `height`, or CSS to control display size. Colors use exact six-digit RGB or eight-digit RGBA hex values. SVG, PNG, and WebP preserve alpha, while JPEG composites transparency onto white.

<View title="React" icon="https://pictum.dev/v1/icons/devicon:react.svg">
  <CodeGroup>
    ```tsx Component
    import { QrCode } from "@pictum/react";

    export function Example() {
      return (
        <QrCode
          value="https://pictum.dev"
          format="svg"
          foreground="#4c1d95ff"
          background="#ede9fe"
          alt="Open Pictum"
          className="size-40"
        />
      );
    }
    ```

    ```tsx Hook
    import { useQrCode } from "@pictum/react";

    export function Example() {
      const asset = useQrCode("https://pictum.dev", {
        format: "svg",
      });

      return <img src={asset.url} alt="Open Pictum" className="size-40" />;
    }
    ```
  </CodeGroup>

  #### Props

  <ResponseField name="value" type="string" required>
    The `value` prop or hook argument is the text or URL to encode. It must be valid UTF-8 containing `1`-`512` bytes.

    <Warning>
      Values may appear in logs and public, cacheable URLs. Do not use sensitive information.
    </Warning>
  </ResponseField>

  <ResponseField name="format" type='"svg" | "jpg" | "png" | "webp"' default="svg">
    The `format` prop or option selects the image encoding. React does not expose raster source size; `width`, `height`, and CSS only control display size.
  </ResponseField>

  <ResponseField name="quietZone" type="boolean" default="true">
    The `quietZone` prop or option includes the recommended clear space around the QR modules. Set it to `false` only when the surrounding layout supplies that space.
  </ResponseField>

  <ResponseField name="foreground" type="string" default="#000000ff">
    The `foreground` prop or option sets the QR module color in exact `#rrggbb` or `#rrggbbaa` format.
  </ResponseField>

  <ResponseField name="background" type="string" default="#00000000">
    The `background` prop or option sets the QR background color in exact `#rrggbb` or `#rrggbbaa` format.
  </ResponseField>
</View>

<View title="URL" icon="https://pictum.dev/v1/icons/tabler:protocol.svg">
  ```text
  https://pictum.dev/v1/qrcode.{format}?data={base64}&foreground={color}&background={color}
  ```

  #### Usage

  ```html
  <img
    src="https://pictum.dev/v1/qrcode.svg?data=aHR0cHM6Ly9waWN0dW0uZGV2&foreground=%234c1d95ff&background=%23ede9fe"
    alt="Open Pictum"
    width="160"
    height="160"
  />
  ```

  #### Parameters

  <ResponseField name="format" type='"svg" | "jpg" | "png" | "webp"' required>
    The path extension selects the response encoding. SVG is dimensionless; raster formats use the requested `size`.
  </ResponseField>

  <ResponseField name="data" type="string" required>
    The `data` query parameter is the standard padded Base64 encoding of a valid UTF-8 value containing `1`-`512` decoded bytes. URL-encode the Base64 when building the request. Base64 is not encryption.

    <Warning>
      Values may appear in logs and public, cacheable URLs. Do not use sensitive information.
    </Warning>
  </ResponseField>

  <ResponseField name="size" type="integer" default="256">
    Requests an exact square raster source from `64` to `2048` pixels. It is ignored for SVG, and HTML attributes or CSS control display size independently.
  </ResponseField>

  <ResponseField name="quiet_zone" type='"true" | "false" | "1" | "0"' default="true">
    Includes the recommended clear space around the QR modules. Use `false` or `0` to disable it; use `true` or `1` to enable it.
  </ResponseField>

  <ResponseField name="foreground" type="string" default="#000000ff">
    Sets the QR module color in exact `#rrggbb` or `#rrggbbaa` format. URL-encode the leading `#` as `%23`.
  </ResponseField>

  <ResponseField name="background" type="string" default="#00000000">
    Sets the QR background color in exact `#rrggbb` or `#rrggbbaa` format. URL-encode the leading `#` as `%23`.
  </ResponseField>
</View>
