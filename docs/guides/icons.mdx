## Usage

Thanks to [Iconify](https://iconify.design/), Pictum brings open-source icon sets together in one catalog. [Browse the Iconify icon gallery](https://icon-sets.iconify.design/) to choose an icon, then use its lowercase kebab-case `prefix:name` identifier, such as `lucide:sparkles`.

<View title="React" icon="https://pictum.dev/v1/icons/devicon:react.svg">
  <CodeGroup>
    ```tsx Component
    import { Icon } from "@pictum/react";

    export function Example() {
      return (
        <Icon
          name="lucide:sparkles"
          aria-label="Sparkles"
          className="size-6 text-violet-600"
        />
      );
    }
    ```

    ```tsx Hook
    import { useIcon } from "@pictum/react";

    export function Example() {
      const asset = useIcon("lucide:sparkles");

      return <img src={asset.url} alt="Sparkles" width={24} height={24} />;
    }
    ```
  </CodeGroup>

  React's `Icon` uses an internal Suspense boundary while it loads the inline SVG.

  #### Props

  <ResponseField name="name" type="string" required>
    The `name` prop or hook argument identifies the icon using exact lowercase kebab-case `prefix:name` syntax.
  </ResponseField>

  <ResponseField name="...props" type="SVG props">
    Additional native SVG props are forwarded to the rendered `<svg>`.
  </ResponseField>
</View>

  #### Usage

  ```html
  <img
    src="https://pictum.dev/v1/icons/lucide:sparkles.svg"
    alt="Sparkles"
    width="24"
    height="24"
  />
  ```

  #### Parameters

  <ResponseField name="prefix:name" type="string" required>
    Replace the path identifier with an exact lowercase kebab-case collection prefix and icon name separated by one colon. Aliases resolve to canonical, dimensionless SVG markup.
  </ResponseField>
