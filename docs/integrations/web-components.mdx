## Installation

Install the Web Components package with your preferred package manager. Custom elements require a browser with Custom Elements, Shadow DOM, and `ElementInternals` support.

<CodeGroup>
  ```bash npm
  npm install @pictum/web
  ```

  ```bash pnpm
  pnpm add @pictum/web
  ```

  ```bash bun
  bun add @pictum/web
  ```

  ```bash yarn
  yarn add @pictum/web
  ```
</CodeGroup>

Call `definePictumElements()` once in a browser entry point. It is safe to call again against the same registry, but registration is not available during server rendering.

## Configuration

Elements use the production Pictum API by default. Set `base-url` on an element when you use another deployment:

```html
<pictum-icon
  name="lucide:sparkles"
  base-url="https://assets.example.com/v1"
  alt="Sparkles"
></pictum-icon>
```

Raw helpers accept the equivalent `{ baseUrl }` option.

## Icons

Use `<pictum-icon>` in markup. Use `icon()` when script code needs the image URL or canonical SVG.

<CodeGroup>
  ```html Component
  <script type="module">
    import { definePictumElements } from "@pictum/web";

    definePictumElements();
  </script>

  <pictum-icon
    name="devicon:html5"
    alt="HTML5"
    class="size-6"
  ></pictum-icon>
  ```

  ```ts Helper
  import { icon } from "@pictum/web";

  // Generate the URL without making a request.
  const url = icon("devicon:html5").url;

  // Fetch canonical SVG markup.
  const svg = await icon("devicon:html5").svg();
  ```
</CodeGroup>

## Avatars

Use `<pictum-avatar>` for generated avatars or portraits. Use `avatar()` when script code needs an image URL; generated avatars also provide canonical SVG markup.

<CodeGroup>
  ```html Component
  <script type="module">
    import { definePictumElements } from "@pictum/web";

    definePictumElements();
  </script>

  <pictum-avatar
    seed="customer-123"
    variant="portrait"
    gender="female"
    format="webp"
    size="256"
    alt="Customer"
    class="size-10"
  ></pictum-avatar>
  ```

  ```ts Helper
  import { avatar } from "@pictum/web";

  // Generate the URL without making a request.
  const url = avatar("customer-123", {
    variant: "portrait",
    gender: "female",
    format: "webp",
  }).url;

  // Fetch canonical SVG markup.
  const svg = await avatar("ada-lovelace", {
    variant: "monogram",
  }).svg();
  ```
</CodeGroup>

## QR codes

Use `<pictum-qr-code>` for scannable text or URLs. Use `qrCode()` when script code needs the image URL or canonical SVG.

<CodeGroup>
  ```html Component
  <script type="module">
    import { definePictumElements } from "@pictum/web";

    definePictumElements();
  </script>

  <pictum-qr-code
    value="https://pictum.dev"
    format="svg"
    quiet-zone="false"
    foreground="#4c1d95ff"
    background="#ede9fe"
    alt="Open Pictum"
    class="size-32"
  ></pictum-qr-code>
  ```

  ```ts Helper
  import { qrCode } from "@pictum/web";

  // Generate the URL without making a request.
  const url = qrCode("https://pictum.dev", {
    format: "svg",
    quietZone: false,
    foreground: "#4c1d95ff",
    background: "#ede9fe",
  }).url;

  // Fetch canonical SVG markup.
  const svg = await qrCode("https://pictum.dev").svg();
  ```
</CodeGroup>

## Placeholders

Use `<pictum-placeholder>` for square or custom-dimension images. Use `placeholder()` when script code needs the selected image URL or SVG markup.

<CodeGroup>
  ```html Component
  <script type="module">
    import { definePictumElements } from "@pictum/web";

    definePictumElements();
  </script>

  <pictum-placeholder
    size="320"
    format="webp"
    density="2"
    background="#ffffff"
    color="#6d28d9"
    text="Coming soon"
    alt="Coming soon"
  ></pictum-placeholder>
  ```

  ```ts Helper
  import { placeholder } from "@pictum/web";

  // Generate a custom-dimension URL without making a request.
  const url = placeholder({
    width: 640,
    height: 360,
    format: "webp",
    density: 3,
    text: "Coming soon",
  }).url;

  // Fetch a square as canonical SVG markup.
  const svg = await placeholder({
    size: 320,
    text: "Coming soon",
  }).svg();
  ```
</CodeGroup>

Every element uses `alt` to label its host for assistive technology. Avatar, QR code, and placeholder elements forward `loading`, `decoding`, `fetchpriority`, `crossorigin`, `referrerpolicy`, `width`, and `height` to their internal image; the icon element renders inline SVG instead. Each element exposes read-only `status` and `error` properties for loading state.

Helpers return an asset immediately. Reading `.url` makes no request; `.svg()` fetches canonical SVG markup and is unavailable for portrait avatars.
